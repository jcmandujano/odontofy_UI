# MVP funcional compartido

El alcance y plan de simplificación se mantienen en la API:

- [Plan en el repositorio de API](https://github.com/jcmandujano/odontofy_node/blob/main/docs/mvp-functional-scope.md).
- [Archivo local con ambos proyectos en el workspace](../../odontofy_node/docs/mvp-functional-scope.md).

Durante la revisión del PR de fase 1, usar el archivo local o la rama `docs/functional-mvp-scope` de API hasta integrar main.

El MVP conserva catálogo de tratamientos para pagos directos, notas generales y odontograma como referencia de hallazgos. Los módulos de tratamientos del paciente, planes y sus integraciones quedan fuera de la experiencia objetivo. Consultar el documento compartido antes de retirar controles, para conservar datos previos y resolver dependencias de notas y pagos.
